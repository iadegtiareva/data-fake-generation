# data-fake-generation

Интерактивная утилита для генерации фиктивных пользователей в CSV с помощью Mimesis. Подходит для подготовки тестовых и демонстрационных данных. Запрашивает путь к файлу, локаль и количество записей.

## Требования и установка

- Python 3.10 или новее — минимальная версия для используемой Mimesis. Проект проверен на Python 3.14.7; остальные версии отдельно не проверялись.
- `mimesis==21.0.0` — генерация данных.
- `typing_extensions==4.16.0` — требуется для импорта Mimesis в проверенном окружении.

Из каталога проекта создайте виртуальное окружение и установите проверенные версии зависимостей:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install mimesis==21.0.0 typing_extensions==4.16.0
```

В Windows вместо `source` используйте `.venv\Scripts\Activate.ps1` в PowerShell. Если команда `python3` отсутствует, используйте `python`, предварительно проверив его версию.

Для тестов используется стандартный `unittest`; дополнительные тестовые зависимости не нужны.

## Запуск

В активированном окружении, из каталога проекта:

```bash
python generate_users.py
```

Пример диалога:

```text
Enter the csv filename (default: users_data.csv):  users.csv
Enter the language (default: en):  ru
Enter the number of rows (default: 100):  3
```

При успешном выполнении в `users.csv` добавятся три записи. Итоговое сообщение об успешной генерации не выводится. Нажмите Enter на каждом запросе, чтобы использовать значения по умолчанию. Параметры вводятся интерактивно, а не через флаги командной строки.

## Параметры и валидация

| Параметр | По умолчанию | Правила |
|---|---|---|
| Путь к CSV | `users_data.csv` | Относительный путь от текущего рабочего каталога или абсолютный путь. Родительский каталог должен существовать. Существующий целевой объект должен быть обычным файлом; ссылка на обычный файл также допускается. |
| Локаль (`locale`) | `en` | Поддерживаемый код из `mimesis.locales.Locale`, например `en`, `ru`, `de`, `en-gb`. Внешние пробелы удаляются, регистр приводится к нижнему: ` RU ` превращается в `ru`. |
| Количество пользователей (`count`, в коде `num_rows`) | `100` | Целое число `>= 0`. Внешние пробелы удаляются, затем значение преобразуется через Python `int()`. Верхний предел не установлен. |

Пустая локаль или количество, в том числе строка из пробелов, означает значение по умолчанию. Для пути только полностью пустой ответ выбирает значение по умолчанию: путь из одних пробелов отклоняется, остальные пробелы в имени сохраняются.

Для пути запрещён нулевой символ. Несуществующий родительский каталог, каталог вместо файла и неработающая символическая ссылка отклоняются. Каталоги автоматически не создаются. Расширение `.csv` не обязательно. `~` и переменные окружения во введённом пути автоматически не раскрываются.

Показать допустимые локали установленной библиотеки:

```bash
python -c "from mimesis.locales import Locale; print(', '.join(item.value for item in Locale))"
```

Количество, локаль и путь проверяются до генерации и открытия CSV. Возможность фактической записи проверяется при открытии и записи файла.

### Ноль и ошибочные значения

При `count=0` локаль и путь всё равно проверяются. Если они корректны, программа завершается с кодом `0`, не генерирует данные, не создаёт и не открывает CSV:

```text
Requested 0 records; file unchanged.
```

Отрицательное число, `abc` или `3.5` вызывают ошибку количества. Неизвестная локаль и некорректный путь также приводят к ошибке, включая запрос с нулевым количеством. Повторного запроса ввода нет: сообщение отправляется в `stderr`, программа завершается с кодом `1`.

```text
Error: count must be an integer >= 0.
Error: unsupported locale: 'xyz'.
```

Окончание входного потока до получения всех ответов обрабатывается как ошибка. Ожидаемые ошибки открытия, записи, закрытия, кодировки и CSV-сериализации выводятся без traceback. Неожиданные внутренние ошибки сохраняют traceback для диагностики.

## Формат CSV

Разделитель — точка с запятой (`;`). Заголовка нет. Каждая запись содержит **13 колонок** в следующем порядке:

| № | Содержимое |
|---|---|
| 1 | Идентификатор по маске `##-##/##` |
| 2 | Логин по маске `U_d`: слово в верхнем регистре, подчёркивание и число |
| 3 | Полное имя |
| 4 | Возраст от 16 до 90 включительно |
| 5 | Профессия |
| 6 | Город |
| 7 | Адрес |
| 8 | Почтовый индекс |
| 9 | Музыкальный жанр из списка `MUSIC_GENRES` |
| 10 | Фильм из списка `MOVIES` |
| 11 | Email с доменом `gmail.com` или `mail.ru` |
| 12 | Телефон |
| 13 | Сгенерированная временная метка Unix, целое число; не обязательно время запуска |

В списках жанров и фильмов по 20 значений. Эти списки общие для всех локалей, их названия не переводятся. Уникальность пользователей и согласованность отдельно сгенерированных города, адреса и индекса не проверяются.

Экранирование полей выполняет стандартный `csv.writer`. Кодировка явно не задана: используется кодировка по умолчанию для текстовых файлов текущего Python-окружения.

Пример одной записи, полученной с локалью `en` (при каждом запуске значения могут отличаться):

```csv
15-55/12;DISASTER_1826;Nery Whitfield;83;Insurance Broker;East Ridge;1078 Avenue C Arcade;64042;Classical;Coco;repository1892@gmail.com;+1-325-631-3086;1780644505
```

## Дописывание и частичные ошибки

Файл открывается в режиме **append** (`"a"`) отдельно для каждой записи. Существующее содержимое не перезаписывается; новые записи добавляются в конец. Отсутствующий файл создаётся при открытии для записи. Схема, кодировка и наличие завершающего перевода строки в существующем файле не проверяются.

При ошибке после нескольких записей исходные данные и уже добавленные записи остаются в файле. Текущая запись может отсутствовать, сохраниться целиком или остаться неполным фрагментом. Автоматического отката, удаления файла и продолжения с места сбоя нет.

При ожидаемой ошибке записи или Ctrl+C после начала вывода сообщение содержит число завершённых записей текущего запуска и предупреждение о неполном результате. Например:

```text
Error: cannot write CSV 'users.csv': Disk full. Completed records in this run: 3. Output may be incomplete. The last attempted record may be incomplete. Check the file before retrying.
```

Счётчик увеличивается только после записи и закрытия файла без исключения. Он не включает прежнее содержимое файла и не гарантирует физическую запись на диск. При сбое закрытия запись может уже присутствовать в CSV, но в счётчик не попадёт. `fsync` не используется.

При ошибке повторного открытия также выводится счётчик и предупреждение о неполном результате, без утверждения о повреждённой последней записи. При ошибке самого первого открытия выводится счётчик `0`.

Перед повторным запуском проверьте файл, особенно его конец: новые данные могут присоединиться к незавершённому фрагменту. Повторный запуск добавляет заново запрошенное количество записей; он не восстанавливает предыдущее задание.

## Коды завершения

| Код | Значение |
|---|---|
| `0` | Успешная генерация или корректный запрос `count=0` |
| `1` | Ошибка валидации, незавершённый ввод или обработанная ошибка работы с CSV |
| `130` | Прерывание пользователем через Ctrl+C |

Необработанные внутренние исключения обычно также завершают процесс с кодом `1`, но сопровождаются traceback.

## Тесты

Из каталога проекта, в окружении с установленными зависимостями:

```bash
python -B -m unittest discover -v
```

Набор содержит 14 тестовых методов с подслучаями. Проверяются генерация для `en` и `ru`, структура CSV, возраст и предпочтения, валидация, нулевой запрос, append, EOF и Ctrl+C, ошибки записи и закрытия, счётчик частичного результата, сохранение traceback внутренних ошибок и импорт без запуска CLI.

Тестовые CSV создаются во временных каталогах и удаляются после проверок. Сбои файловых операций имитируются через mocks. Успешный запуск завершается сообщением `OK` и кодом `0`.
